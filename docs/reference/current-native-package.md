## Required producer gates

Each fresh native producer runs strict source/kit guards, builds all four
portable binaries, and checks their actual compiler and package identities.
It runs Trident's library tests, the complete Nox std library tests, and the
Trisha and Joy CPU suites with the built package's flags. The long Trident
integration suite is not reported as newly executed: a change-impact receipt
requires unchanged compiler implementation/fixtures and identifies the frozen
six-platform evidence and the separately validated Nox observer change.

The existing installed/unpacked kit checks, runtime and process/file probes,
Neptune binding/mock-client tests, all 133 baseline executions, fresh installed
legacy proof smoke, 47 legacy corpus cases, LSP protocol smoke, deterministic
repack and unpacked binary identity checks all run against the new binaries.

An additional installed Joy gate consumes the committed public artifact and
small compiler-envelope vectors. It proves and verifies complete nouns, a
bounded loop, successful compiler output and compiler diagnostics in fresh
processes. Positive outputs must match exact expected noun bytes. Wrong input,
wrong program, truncated/corrupt certificate and invalid extraction checks must
reject, preserve the existing destination and leave no temporary publication.
These small fixtures do not establish whole-compiler SH7/SH8 acceptance.

The new local Mac package receives its own actual 198-proof gate after the
existing frozen local run ends. It uses the unchanged 28 GiB proof RSS guard,
Rayon 4, host-memory guard and source/binary mutation checks. The frozen 198
receipt remains a result for its original binary identities. It is never
marked as an execution against a rebuilt package.

## Corpus and transport

Retain both the fresh legacy corpus and a separate public structured corpus.
The latter binds the exact producer Joy binary, complete source provenance,
fixture inventory, certificate bytes and expected outputs. Its independent
consumer invokes only the selected installed Joy executable with fixed
arguments and bounded subprocesses; corpus data never supplies shell code.

Every one of the six fresh native consumers verifies all six producer corpora
of both kinds. The original authenticated Actions containers, portable binary
archives, both corpora, actual host/toolchain records and all command receipts
are retained. Uploads require exact source/kit identity, native compiler
identity, source-selected hashes, unique asset names, server digest agreement,
an existing unpublished draft and continued tag absence.

The gate matrix records newly executed checks, inherited source-level evidence,
proposed floors and unexecuted checks separately. A green old run cannot change
the source or binary identity of the new run.
