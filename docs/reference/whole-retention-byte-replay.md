# Separate remote certificate byte replay

This is a new transport observation profile. It preserves the original local
adoption run and its exact source, limits, partial bytes and eventual result.
It never reports a remote download as a successful local download. No proof
generation, native verifier/compiler execution, certificate rewrite, part
upload, release/tag creation, overwrite, promotion or automatic retry is added.

The canonical SH8 contract (`trident/reference/self-hosting.md`, SH8) requires
complete compilation proofs, fresh verification and the bound acceptance
receipts. It does not prescribe the geographical/host location of an independent
complete-body transport replay. The approved local adoption PLAN.md describes
one concrete local process. This separate profile can supply the independent
complete-byte observation only with explicit remote provenance and a new local
closure; it cannot change the old command's status. Original local metadata
retention and the distinct equivalence manifest remain mandatory.
